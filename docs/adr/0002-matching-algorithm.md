# ADR 0002 — 违禁词匹配算法：Aho-Corasick 多模自动机

- 状态：已采纳
- 日期：2026-08-16

## 背景

监控引擎需对每次捕获到的文本（单个输入框内容，通常数十到数百字）实时匹配词库。词库规模可能从几十条增长到上千条；且同一段文本可能命中多个词。要求匹配不卡顿客服软件。

## 决策

采用 **Aho-Corasick 多模自动机**：将词库编译成自动机后，对文本做单次线性扫描即可找出所有命中词，时间复杂度 O(文本长度 + 命中数)。词库更新时重建自动机（低频，热更新）。

## 取舍

- 优点：与词库规模无关的高效匹配；原生支持"一次扫描多命中"；适配中文子串匹配。
- 缺点：实现比朴素 `Contains` 循环复杂（但可用成熟开源实现，如 `AhoCorasick` .NET 库或自研约 200 行）。
- 备选已排除：朴素子串扫描（词库大时 O(词数×文本) 可能卡顿）；正则（灵活但有误匹配与回溯性能风险，且中文违禁词多为精确串）。

## 影响

- 词库加载/更新流程需包含"重建自动机"步骤。
- 命中结果需返回词面、位置、所属词库条目（含分级/处理结果），供告警与日志使用。
