违禁词管理

维护被监控软件中禁止出现的高危词汇，支持分级与分类。

词汇分类级别启用操作

提示：本端维护词库与默认策略（随词库一并下发）；客户端可另行覆盖本机生效值。

分类管理

对违禁词进行归类，便于批量管理与告警分析。

分类由词条动态生成；删除分类时，其下词条可迁移到指定分类（留空则归入「未分类」）。

默认策略

监控目标与告警方式默认值，随词库一并下发；客户端可覆盖本机生效值。

监控目标软件

每行一个：EXE 名 或 EXE 名 | 路径前缀（留空路径 = 仅按 EXE 名）。

告警通道

命中违禁词时的默认提醒形式。

去重窗口同一词同一会话 N 秒内不重复告警
日志保留客户端本地审计日志保留天数

客户端管理

将词库与默认策略统一下发到各监控客户端。

文件式分发（当前架构）

本版本采用「导出词库文件 → 拷贝到客户端安装目录覆盖 wordlib.json」的下发方式，客户端监控引擎会自动热加载新词库，无需重启。导出词库 会打开另存为对话框，生成带时间戳的 wordlib 文件供分发。

说明：管理端不再包含「本机部署」——本机运行时的监控目标 / 告警开关由客户端在「监控状态」面板中配置；管理端只负责词库与默认策略下发。

新增违禁词

添加到词库并随默认策略一并下发。

新建分类

分类用于组织违禁词，随词条一并保存在词库中。

确认操作
此操作不可撤销。
